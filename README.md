# MeuSaldo
 
Organize seu dinheiro. Planeje seu futuro.
 
Projeto escolar de Desenvolvimento de Sistemas: uma página de educação
financeira com uma calculadora de orçamento mensal.
 
## Objetivo
 
Ajudar a pessoa a descobrir quanto sobra da renda depois dos gastos fixos
e sugerir como distribuir esse valor entre reserva de emergência,
investimentos e metas, e lazer.
 
## Tecnologias
 
- HTML: estrutura e conteúdo da página
- CSS: aparência e adaptação para celular
- Python (somente biblioteca padrão): cálculos e servidor local
 
Sem Flask, sem JavaScript, sem banco de dados e sem instalar bibliotecas.
 
## Funcionalidades
 
- Soma das rendas e dos gastos fixos
- Saldo restante e percentual da renda comprometido
- Avisos quando os gastos superam a renda
- Distribuição do saldo com percentuais ajustáveis (soma 100%)
- Calculadora de metas (valor dividido pelo número de meses)
- Validação de campos vazios, negativos ou inválidos
 
## Como executar
 
1. Tenha o Python 3 instalado.
2. Abra um terminal na pasta do projeto.
3. Digite: `python app.py` (ou `py app.py` no Windows).
4. Abra no navegador: http://127.0.0.1:8000
5. Para parar: Ctrl + C no terminal.
 
## Limitações
 
Os dados não são salvos: eles viajam no formulário e somem ao fechar a
página ou parar o servidor. O GitHub guarda o código, mas não executa o
Python: para usar o sistema é preciso rodar o app.py em um computador.
 
## Aviso
 
Conteúdo educativo. Não substitui aconselhamento financeiro individual.
